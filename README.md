# Uma Tools – simulator extension

This repository is a fork of [alpha123/uma-tools](https://github.com/alpha123/uma-tools), an open-source Uma Musume race simulator.

The mechanics solver is based on [alpha123/uma-skill-tools](https://github.com/alpha123/uma-skill-tools).

The original simulator, solver, game data, assets, and historical implementation are credited to alpha123 and the original contributors. This fork is not affiliated with Cygames or *Uma Musume: Pretty Derby*.

## What this fork adds

- Expanded field and runner-interaction simulation
- More detailed skill-condition handling
- Median race replay and acceleration telemetry
- Experimental full-field simulation mode
- Skill and Uma comparison tables
- Additional data audits and regression tests
- GitHub Pages deployment and upstream-sync automation
